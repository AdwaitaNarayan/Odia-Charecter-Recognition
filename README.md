🌟 Odia Alphanumeric Character Recognition
🧠 Project Overview

This project focuses on building an AI-powered OCR (Optical Character Recognition) system capable of accurately identifying Odia alphanumeric characters — a crucial step toward enabling regional language digitization and accessibility.

By leveraging deep learning techniques, the model can read and recognize Odia letters, numerals, and composite characters from scanned or handwritten images, making it valuable for educational, governmental, and linguistic applications.

🚀 Key Features

🔤 Recognizes Odia alphabets and numerals

🖼️ Image preprocessing (noise removal, binarization, resizing)

🤖 Deep learning model (CNN/LSTM-based architecture) for classification

📊 High accuracy on custom Odia dataset

💾 Supports both printed and handwritten text

🌐 Easy integration for OCR-based applications

🧩 Tech Stack

Python 🐍

TensorFlow / Keras / PyTorch (for model training)

OpenCV / PIL (for image preprocessing)

NumPy / Pandas / Matplotlib (for data handling and visualization)

🧪 Results

The model demonstrates strong performance in recognizing Odia characters from noisy and handwritten inputs. Continuous improvements are being made to enhance accuracy and expand dataset coverage.
